# Route map source

`src/assets/home/zaria-dotmap.svg` and the route geometry in `src/components/home/Reach.astro`
were generated by `gen-map.mjs` (d3-geo, topojson-client and world-atlas; not installed in this
project). `map-geometry.json` holds the projected city points and the six routes, each
from Abu Dhabi to one city, in the map's 1200 x 680 coordinate space, with each route's length
(it sets the size and timing of the route's light, the `.c0` to `.c5` rules in `Reach.astro`). To change the cities, install those packages in a scratch folder,
edit the points and legs in `gen-map.mjs`, run it, and copy the new paths into `Reach.astro`.
